GAS Auth SPA Template

Google Apps Script + Google Identity Services 架構說明

1 專案概述

這是一個基於 Google Apps Script (GAS) 的 Web 應用程式範本，採用 Google Identity Services (GIS) 認證與 SPA (Single Page Application) 架構，具備跨網域權限管理功能。

🔐 GIS 認證

使用 Google Identity Services 進行 OAuth 2.0 / OpenID Connect 認證

📄 SPA 架構

單一 HTML 入口，前端路由切換不同頁面區塊

🛡️ 後端防護

基於 JWT Token 與角色的後端驗證機制

3 認證流程

1
使用者載入 Web App
GAS doGet() 回傳 index.html，前端開始載入 GIS SDK
2
初始化 Google 認證
前端呼叫 google.accounts.id.initialize()，渲染登入按鈕並顯示 One Tap
3
使用者點擊登入
Google 核發 ID Token (JWT) 給前端，包含使用者 Email 與基本資料
4
前端傳送 Token 到後端
透過 google.script.run.loginWithToken(token) 將 ID Token 傳送到 GAS 後端
5
後端驗證 Token
validateIdToken() 呼叫 Google Token Info API 驗證，檢查 Audience、Issuer、過期時間
6
檢查權限與角色
checkEmailPermission() 檢查網域與白名單 → verifyRole() 檢查角色權限
7
回傳結果，前端切換畫面
後端回傳使用者資料，前端根據角色渲染對應的儀表板區塊

5 後端模組說明 (Code.js)

函式名稱 類別 功能說明
doGet(e) Web App 處理 GET 請求，回傳 index.html SPA 框架
validateIdToken(token) 認證 驗證 JWT Token（呼叫 Google Token Info API）
checkEmailPermission(email) 權限 檢查 Email 網域與白名單
verifyRole(token, requiredRoles) 權限 核心中介層：驗證 Token + 檢查角色權限
loginWithToken(token) API 登入 API：驗證 Token 並回傳使用者身分
getProtectedData(token) API 受保護的範例 API：依角色回傳不同資料
getWebsiteParameter(name) 工具 從試算表讀取單一網站參數
getWebsiteParameters() 工具 一次讀取所有網站參數（JSON 格式）
getUserFromSheet(email) 工具 從帳號管理工作表查詢使用者
onOpen() 試算表 試算表開啟時建立自訂選單

6 角色權限模型

admin / 管理員
系統負責人
  • ✅ 管理所有設定
  • ✅ 管理所有帳號
  • ✅ 存取所有資料
  • ✅ 系統統計資料
teacher / 導師
教職員、班導師
  • ❌ 管理系統設定
  • ✅ 管理學生名單
  • ✅ 存取班級資料
  • ❌ 系統統計資料
student / 學生
一般使用者
  • ❌ 管理系統設定
  • ❌ 管理學生名單
  • ✅ 存取個人資料
  • ✅ 查看成績與作業
